Growth → inversion

Generation 0 holds the seeds. Each generation defines every word the one before it used. Growth stops when the per-letter word pools are used up, so the ball has to close.

The rules

1Self-anchor. Slot 1 is the word itself: THINK = Think Hi Ideal Nice Knowledge.
2Positive pool. Each other slot comes from a short list of positive words for its letter.
3Explore. While the ball grows, each slot takes the least-used word for its letter, so meaning spreads out.
4Close. A word gets defined the generation after it first appears. The pools are finite, so growth has to stop.
5Prune. Each letter collapses to its most-used word (its anchor). Words that nothing reaches are dropped.
6Locked. Hand-written seeds are never rewritten.
7Two meanings. A seed can carry a second meaning. The source meaning builds the ball, and the second meaning is shown underneath. Example: BBOOPPPPIITT.
